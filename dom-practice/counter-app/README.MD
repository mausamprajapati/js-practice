# Counter App

A counter that increases, decreases, and resets, and change background color based on the value.

## Features
- Increase and Decrease value with + and - button.
- Reset to 0 with reset button.
- Change the background color green when positive, red when negative, and white when 0.

## Built with
HTML, CSS JavaScript (DOM Manupulation and Event listeners)

## How to Run
Download the folder and open index.html in your browser.
